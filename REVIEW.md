# Review Guidelines

`elsewhere` reads URLs through an in-process Xray-core and prints or serves the result.
`Sources/ElsewhereKit/ElsewhereKit.docc/Design.md` is authoritative; check changes
against it.

## Critical Areas

- Flag a path where a share link, its UUID, or a `pbk`/`sid`/password value can reach
  stdout, stderr, a log line or an error's `errorDescription` without passing through
  `Redactor`.
- Flag an engine error message surfaced without `Redactor.scrub(_:secrets:)` — the engine
  can echo config text back.
- Flag `allowFailover` set to true, or any silent fallback to a direct connection when an
  exit or the tunnel fails — an unannounced path switch is a leak.
- Flag a public signature in `Sources/ElsewhereKit/` that names an `XrayCore` or
  `ArgumentParser` type, or a `public import` of either — they are implementation details.
- Flag an untyped `throws` on a public member in `Sources/ElsewhereKit/`; it must be
  `throws(ElsewhereError)`.
- Flag a `log` block in `Sources/ElsewhereKit/XrayConfigBuilder.swift` that is not one of
  `XrayLog`'s two shapes — the engine logs to stdout, which is the payload or the
  protocol.
- Flag an `exitStatus` change in `Sources/ElsewhereKit/ElsewhereError.swift` whose PR
  does not also change `ExitStatus.rows` and the README table.
- Flag test code under `Tests/` that opens a non-loopback connection: the suite is
  offline by contract.

## Conventions

- Config writes in `Sources/ElsewhereKit/ConfigStore.swift` must keep the directory 0700
  and the file 0600 — flag a write path that drops either.
- In `Sources/elsewhere/`, `--link -` (stdin) must stay the only link path that avoids
  argv; a link on the command line lands in shell history and `ps`.

## Anti-patterns to Flag

- Reject `try!` and force unwraps outside `Tests/`, except `URL(string:)` on a literal
  constant.
- Flag `print(` in `Sources/elsewhere/` — output goes through `emit`/`printError`
  (unbuffered, right stream) and errors through `reportingErrors`.
- Flag goldens under `Tests/ElsewhereKitTests/Fixtures/` edited by hand instead of
  regenerated by the builder (`ELSEWHERE_WRITE_GOLDENS=1`).

## Ignore

- Skip `Package.resolved` churn when the PR only bumps a dependency pin.
- Skip `Tests/ElsewhereKitTests/Fixtures/` byte-content comments beyond "regenerated by
  the builder".
